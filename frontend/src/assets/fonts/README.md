# Bundled fonts

Space Grotesk and JetBrains Mono are distributed under the SIL Open Font License 1.1. Their license files are retained alongside the font files.

Sources:
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Fonts are served from the application itself; no external font requests are made by the browser.
